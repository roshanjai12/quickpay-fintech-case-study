### Query
The SQL query was used to identify the top 10 merchants based on total captured GMV from the cleaned transaction dataset. Only successfully captured transactions were considered for calculating the merchant-wise payment volume.

### Result Summary
The analysis ranked merchants according to their total successful transaction value processed in USD. The query grouped transactions using standardized merchant names, calculated the cumulative captured GMV for each merchant, and displayed the top performing merchants in descending order of revenue contribution.

This analysis is useful for identifying key business contributors, understanding merchant performance distribution, and monitoring merchant-level transaction trends within the QuickPay payment ecosystem. The output can also support dashboard leaderboards, revenue analysis, and strategic merchant relationship management.

-- Q4
SELECT
    transaction_date_clean,
    SUM(amount_usd) AS daily_gmv,
    COUNT(*) AS successful_transaction_count
FROM transactions
WHERE status_clean = 'CAPTURED'
GROUP BY transaction_date_clean
ORDER BY transaction_date_clean;
